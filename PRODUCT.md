Support Qur’an memorization review, review of Saturday and Tuesday halaqas, weekly quizzes and a shared leaderboard.

## Sunday Preparation and In-person Review
The owner confirmed students are 10–17, using the site mostly on Sundays and also for weekday revision. The core loop is exact assigned work → practise → complete an attached short check → report ready or ask for help → teacher review in person. Digital readiness does not verify recitation and never awards leaderboard points.

Teachers assign Qur’an, halaqa, quiz or other work to everyone or one active account. Qur’an assignments carry a validated surah/ayah range and memorisation/review goal. Halaqa assignments carry a supported YouTube video or playlist and can attach a published quiz; quiz assignments require a published quiz. Other work has instructions. The editor previews the resulting student action. Title-only edits preserve progress; changes to the actual work reset it with explicit wording. Removal withdraws the assignment from students, with Undo removal and later restore preserving previous progress. Assignment revisions, progress versions, idempotent creation and bounded 15-second requests protect stale/repeated writes; failed saves retain drafts.

Students use Open assigned ayahs to reach the Qur’an tab with the full surah and their validated teacher-assigned ayahs highlighted in gold. The week’s accessible Qur’an assignments remain selectable there; assignment/week links use the current API revision, warn when work is withdrawn and offer retry or independent reading when homework cannot load. Practice first asks for an ayah range, prefilled with the exact active assignment and bounded to it; independent practice starts with up to five ayahs of the current passage. Short three/five-ayah presets and Whole assignment/passage remain explicit choices. Reveal ayah stays central: recite from memory, optionally ask for the source’s first word, reveal the attributed Tajweed text, then choose Practise this ayah again or Remembered it. Practise this ayah again immediately repeats the same current ayah without moving its position, hides the answer and resets the hint; a Same ayah note explains the retry. Only Remembered it advances. Progress counts the student’s remembered checks, without a mastery or retention claim. This session is temporary private rehearsal, with no saved spaced-repetition schedule, recording, automatic grading or points. Back to homework returns to the originating task; practice never writes readiness, which students report separately before the teacher checks recitation in person. Assigned lessons open their player and external fallback; attached quizzes use actual saved completion before readiness unlocks. An unavailable attached quiz leaves help available. Pending, ready, help, repeat and reviewed states, plus teacher feedback, are private to the student and teacher. The teacher’s visible Assigned work / Review in person views support reviewing any assigned active student, including someone who never checked in digitally.

Sunday defaults to today when today is Sunday, otherwise the upcoming device-local Sunday. A native calendar maps another chosen weekday forward to Sunday; week arrows move seven days. The full localized date and input remain visually separate on narrow screens.

## Student Roster and Removal
Teachers can search active or archived accounts. Archive preserves history, revokes sessions and blocks further sign-in and legacy anonymous writes under the archived name. Restore permits a new sign-in. Permanent deletion is offered only after archive, with exact-name confirmation and a preview of affected record counts. An atomic revision/count guard rejects a stale preview. Deletion removes the account, photo/identity fields, sessions, individual assignments/progress, account submissions and legacy name-matched submissions, grades, shared notes and approved moments; unrelated accounts’ records remain. Deletion does not prohibit a future new account; archive is the retained disabled-account state.

## Qur’an Source and Boundaries
The public Qur’an tab is a 114-surah library with Arabic/English/name-or-number search, full-surah selection, previous/next surah, optional exact range, reading and private recall. Its continuous mushaf composition uses inline green ayah listening buttons, dedicated self-hosted Amiri Quran and a quiet ivory sheet inside the existing Najdi shell. Text-size controls use a 24–48px setting, initially 36px. Save place explicitly stores the selected ayah on this device, with a resume action. Remove saved ayah clears only this device’s bookmark, with Undo removal. Storage failure preserves the saved place and shows a nearby error; keyboard focus moves to Undo after removal and Resume after restoration. This is reflowable reading, not fixed printed-page pagination. Homework now opens this public reader with full-surah context and gold assignment highlights; the practice range is prefilled from the active assignment and may be narrowed within it. Reveal ayah, optional first-word hint and immediate same-ayah retries extend the existing recall interaction. Changing the selected Sunday clears the old Qur’an homework context.

Attributed Al Quran Cloud `quran-tajweed` text supplies Tajweed rule annotations. Nested and untyped annotation metadata becomes React text runs; Arabic characters, diacritics and order are preserved. A bilingual key explains 17 rule categories with colors darkened for legibility on the reading sheet. Text is never inserted as provider HTML or rewritten by AI. Successful responses are cached; bounded requests, validation, cancellation and visible retry remain.

Muhammad Siddiq Al-Minshawi — Murattal is the built-in default, using trusted EveryAyah verse audio. A native bilingual reciter selector adds the current Al Quran Cloud Arabic verse-by-verse catalog, deduplicating recording variants. Mishary Alafasy and his variants are excluded at the owner’s request; no reason or factual allegation is implied. Choice is saved on this device, and an excluded or unavailable saved choice falls back to Al-Minshawi. The default remains usable if the additional catalog fails, with visible retry. The observed catalog currently yields 17 choices including the built-in default; the provider catalog can change. Other reciter audio must match the exact selected edition and trusted CDN path. Changing reciter, range, mode or ayah cancels previous audio; public passage playback advances ayah by ayah. Text and audio retain separate source links. On mobile, reading comes first, the visible Reciter & audio link reaches controls below the text, and native playback controls float only while audio is loaded, with space reserved below the reader.

The teacher picker still uses the bundled 114-surah metadata list. The teacher progress extension and migration 0010 require the matching backend release. Production Foundation endpoints remain disabled. Sacred text is content, never ornament; practice and readiness do not grade recitation or award points.

Teacher checks show the latest saved result for each included assignment, even when recorded after the cutoff; this is not a historical as-of snapshot. Search and All students / Needs attention filter active accounts; archived accounts and withdrawn work are excluded. Each student’s detail shows assigned Qur’an passages with exact range, memorisation/review goal and date, current readiness separately from the latest teacher check, and teacher feedback. Record check opens an inline editor: Needs more practice requires a short instruction; Mark reviewed accepts optional feedback. Teacher-checked coverage counts unique overlapping ayahs once, with no mastery percentage or claim of an append-only attempt history. Assign homework for this student prefills the student and passage context; the teacher chooses and publishes the next work explicitly.

Teacher checks persist separately in assignment_progress.teacher_status and teacher_reviewed_at (migration 0010), so a later student ready/help update changes readiness while preserving the last teacher check and feedback. Backfill accepts only known reviewed/repeat records with a review date. The existing optimistic revision/version guard protects teacher writes. Changing actual assignment work still resets its progress and teacher proof; title-only edits preserve it. Removal withdraws work, excluding it from student and progress views; Undo and restore retain marks. Existing permanent-account deletion removes the progress rows including these fields. The teacher-only same-origin GET /api/quran-progress returns roster or selected detail with no-store caching and introduces no provider or API key.

Remove homework remains visible in the assignment list, Remove this homework inside Edit, and Remove homework / Remove for everyone on progress rows with explicit scope.
